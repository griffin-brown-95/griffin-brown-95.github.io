Speed skating · US Speedskating short track

Blade Runner

View code

Practice-lap analytics for US Speedskating's short track group at the Utah Olympic Oval. Every lap is timed by MYLAPS transponders on a 111 m track; Blade Runner scrapes those public timing feeds nightly, models them into skaters, sessions and laps, and publishes a dashboard the coaching staff can open from anywhere — with no servers and no cloud bill.

Automated ingestion

A GitHub Actions workflow scrapes nightly, commits the database and redeploys the site. Backfills run by date range.

Lap-level data model

Transponder-days split into continuous on-ice sessions and individual laps, with a chip → skater mapping layer.

Training metrics

Sessions, lap volume, fastest and average lap and time on ice per skater per day, rolled up into season totals.

Zero-infrastructure deploy

Static dashboard on GitHub Pages; the team forks the repo to run their own. Views are portable to Snowflake.
